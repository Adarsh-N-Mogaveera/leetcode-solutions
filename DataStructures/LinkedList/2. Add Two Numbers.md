# 2. Add Two Numbers

## Approach

### Approach Explanation

The solution simulates the standard pen-and-paper addition algorithm, processing the digits from the least significant to the most significant (left-to-right, as the linked lists are already reversed).

#### Core Idea & Mechanism
* **Carry Management**: A single variable `sum` serves a dual purpose: it accumulates the sum of the current digits and stores the carry-over (either `0` or `1`) for the next iteration.
* **Three-Phase Traversal**:
  1. **Overlap Phase**: It traverses both lists simultaneously, adding corresponding digits along with any existing carry. If the sum is $\ge 10$, a node with `sum - 10` is created, and the carry (`sum`) is set to `1`. Otherwise, a node with `sum` is created, and the carry is reset to `0`.
  2. **Remaining Phase**: If one list is longer than the other, it continues the same addition and carry-propagation logic for the remaining nodes of the longer list.
  3. **Final Carry**: After exhausting both lists, if a carry of `1` remains (`sum != 0`), a final node with value `1` is appended to the end of the list.
* **Pointer Tracking**: The `res` pointer stores the head of the new list, while the `move` pointer dynamically appends new nodes and advances to track the tail.

---

### Complexity Analysis

* **Time Complexity**: $\mathcal{O}(\max(N, M))$, where $N$ and $M$ are the lengths of the linked lists `l1` and `l2`. The algorithm processes each node of both lists at most once.
* **Space Complexity**: $\mathcal{O}(\max(N, M))$ to store the newly created result linked list. Excluding the memory allocated for the output list, the auxiliary space complexity is $\mathcal{O}(1)$ as it only uses a few pointers and an integer variable.

## Code

```Java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        int sum = 0;
        ListNode res = null;
        ListNode move = res;
        ListNode temp = res;

        while(l1 != null && l2 != null) {
            sum += l1.val + l2.val;

            if(res == null) {
                if(sum >= 10) {
                    res = new ListNode(sum - 10);
                    sum = 1;
                }

                else {
                    res = new ListNode(sum);
                    sum = 0;
                }
                l1 = l1.next;
                l2 = l2.next;
                move = res;
            }

            else {
                if(sum >= 10) {
                    temp = new ListNode(sum - 10);
                    sum = 1;
                }

                else {
                    temp = new ListNode(sum);
                    sum = 0;
                }

                l1 = l1.next;
                l2 = l2.next;
                move.next = temp;
                move = temp;
            }
        }

        while(l1 != null) {
                sum += l1.val;
                if(sum >= 10) {
                    temp = new ListNode(sum - 10);
                    sum = 1;
                }

                else {
                    temp = new ListNode(sum);
                    sum = 0;
                }
                l1 = l1.next;
                move.next = temp;
                move = temp;
            }

            while(l2 != null) {
                sum += l2.val;;
                if(sum >= 10) {
                    temp = new ListNode(sum - 10);
                    sum = 1;
                }

                else {
                    temp = new ListNode(sum);
                    sum = 0;
                }
                l2 = l2.next;
                move.next = temp;
                move = temp;
            }

            if(sum != 0) {
                temp = new ListNode(sum);
                move.next = temp;
                move = temp;
            }

        return res;
    }
}
```
