# 3014. Minimum Number of Pushes to Type Word I

## Approach

### Core Idea

The approach uses a **greedy distribution strategy** to minimize keypresses. Since there are 8 available physical keys (typically 2–9 on a telephone keypad) and all characters in the input word are distinct, we minimize the total cost by distributing letters as evenly as possible across these 8 keys. 

We assign the first 8 characters to the first position of each key (requiring 1 push each). The next 8 characters are assigned to the second position (2 pushes each), the next 8 to the third position (3 pushes each), and so on.

### Why It Works

* **Layered Allocation:** By grouping keys in blocks of 8, we ensure that we never use a higher-cost keypress (e.g., 2 or 3 pushes) before completely exhausting all available lower-cost slots (1 push).
* **Mathematical Progression:** The variable `count` tracks the current cost layer (starting at 1). For each full group of 8 characters processed, the code accumulates $8 \times \text{count}$ to the total and increments `count`. Any remaining characters at the end are multiplied by the final `count` layer.

### Complexity

* **Time Complexity:** $\mathcal{O}(N)$ where $N$ is the length of the word (to compute `word.length()`). The mathematical calculation itself runs in $\mathcal{O}(1)$ auxiliary time since $N \le 26$ (the English alphabet size), limiting the loop to a maximum of 3 iterations.
* **Space Complexity:** $\mathcal{O}(1)$ as the algorithm only uses a few primitive integer variables (`temp`, `max`, `count`) to compute the result.

## Code

```Java
class Solution {
    public int minimumPushes(String word) {
        int n = word.length();
        int temp = n;
        int max = 0;
        int count = 1;
        if(temp >= 8) max = 8;
        else return n;
        temp -= 8;
        count++;
        while(temp > 8) {
            max += 8 * count;
            count++;
            temp -= 8;
        }

        max += temp * count;

        return max;
    }
}
```
