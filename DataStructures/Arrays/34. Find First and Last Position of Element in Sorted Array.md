# 34. Find First and Last Position of Element in Sorted Array

## Approach

### Approach Explanation

The solution uses a two-pass binary search approach to independently find the starting (first) and ending (last) positions of the target element in $O(\log n)$ time.

#### Core Idea & Mechanism
1. **First Occurrence Search**: 
   * A standard binary search is performed to find the leftmost boundary. 
   * When `nums[mid] == target`, the index is recorded in `arr[0]` as a potential first position. Crucially, the search space is then restricted to the left half (`high = mid - 1`) to check if the target appears earlier in the array.
2. **Last Occurrence Search**: 
   * The binary search is reset and run a second time to find the rightmost boundary.
   * When `nums[mid] == target`, the index is recorded in `arr[1]` as a potential last position. The search space is then restricted to the right half (`low = mid + 1`) to check if the target appears later in the array.

If the target is not present in the array, the search loops terminate without modifying the initial value of `-1` for the respective index.

---

### Complexity Analysis

* **Time Complexity**: $\mathcal{O}(\log n)$  
  The algorithm performs two independent binary searches sequentially. Each search halves the search space at every step, resulting in $2 \times \mathcal{O}(\log n) = \mathcal{O}(\log n)$ time complexity.
  
* **Space Complexity**: $\mathcal{O}(1)$  
  The search is performed in place using pointers (`low`, `high`, `mid`). Only a constant amount of extra memory is used to store the output array of size 2.

## Code

```Java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int[] arr = new int[2];
        arr[0] = arr[1] = -1;

        int low = 0;
        int high = nums.length - 1;

        while(low <= high) {
            int mid = (low + high) / 2;

            if(nums[mid] == target) {
                arr[0] = mid;
                high = mid - 1;
            }

            else if(nums[mid] > target) {
                high = mid - 1;
            }

            else {
                low = mid + 1;
            }
        }

        low = 0;
        high = nums.length - 1;

        while(low <= high) {
            int mid = (low + high) / 2;

            if(nums[mid] == target) {
                arr[1] = mid;
                low = mid + 1;
            }

            else if(nums[mid] > target) {
                high = mid - 1;
            }

            else {
                low = mid + 1;
            }
        }

        return arr;
    }
}
```
