# 1979. Find Greatest Common Divisor of Array

## Approach

### Core Idea
The solution finds the minimum and maximum elements in the array and computes their Greatest Common Divisor (GCD) by testing candidate divisors in descending order.

### Why It Works
1. **Finding Extremes:** A single-pass scan over the array identifies the minimum (`min`) and maximum (`max`) values.
2. **Search Space Bounding:** The GCD of two numbers cannot be larger than the smaller of the two numbers. Therefore, the search space for the GCD is bounded by $[1, \text{min}]$.
3. **Reverse Linear Search:** By iterating backwards from `min` down to `1`, the first integer $i$ that divides both `max` and `min` without a remainder (`max % i == 0` and `min % i == 0`) is mathematically guaranteed to be the greatest common divisor.

### Complexity Analysis

* **Time Complexity:** $\mathcal{O}(N + M)$, where $N$ is the length of the array and $M$ is the value of the minimum element. 
  * Finding the minimum and maximum takes $\mathcal{O}(N)$ time.
  * The loop to find the GCD runs at most $M$ times. 
* **Space Complexity:** $\mathcal{O}(1)$ auxiliary space, as the algorithm only uses a few integer variables for tracking the extremes and the loop state.

## Code

```Java
class Solution {
    public int findGCD(int[] nums) {
        int n = nums.length;
        int min = nums[0];
        int max = nums[0];

        for(int i : nums) {
            if(i < min) min = i;
            if(i > max) max = i;
        }

        for(int i = min; i >= 1; i--) if(max % i == 0 && min % i == 0) return i;

        return -1;
    }
}
```
